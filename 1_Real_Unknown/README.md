# 1_Real_Unknown - Objectives (OKRs)

## Primary Objective

Automate essential post-production workflows in DaVinci Resolve to streamline the editing process using Python scripting.

## Key Results (Goals)

1. **Visual Elements Automation**
    * [ ] Implement script to auto-add overlays to footage.
    * [ ] Implement script to import and place images on the timeline.
    * [ ] Implement script to add motion graphics/titles.

2. **Metadata & Structure**
    * [ ] Create functionality to generate timeline chapters automatically.
    * [ ] Create functionality to place markers at specific timecodes or events.

3. **Audio Processing**
    * [ ] Develop a script to normalize audio levels across the timeline.

## Unknown Problems / Research Area

* Limitations of the DaVinci Resolve API regarding specific effect controls.
* Handling diverse footage resolutions and framerates automatically.
