# DavinciResolveScripting
Fusion with Python Davinci Resolve scripting

## Project Structure

### 1_Real_Unknown - Objectives (OKRs)
Defines project objectives and key results, start with the unknown problem.

### 2_Environment - Roadmap and Use Cases
Contains the project roadmap with development phases and detailed use cases for different user scenarios.

### 3_Simulation - UI
User interfaces and technologies used, including HTML5, CSS3, JavaScript, and best practices for UI development.

### 4_Formula - Guides and Best Practices
Provides guidelines built by GPT.

### 5_Symbols - Core Source Code
Contains the main application files.

### 6_Semblance - Error Logs and Solutions
Documents common issues, their causes, and solutions. Includes debugging tips and workarounds for browser compatibility.

### 7_Testing_known - Validation
Contains test plans, validation procedures, and acceptance criteria for ensuring application quality to reach the objectives in real and reach a known world.
