# 2_Environment - Roadmap and Use Cases

## Project Roadmap

### Phase 1: Foundation

* Setup Python scripting environment for DaVinci Resolve.
* Establish connection to the `Resolve` object and `ProjectManager`.

### Phase 2: Visuals & Graphics

* **User Story**: As an editor, I want to automatically place watermarks/overlays on all clips so I don't have to do it manually.
* **User Story**: As an editor, I need to import a clear set of graphics/images at specific points.

### Phase 3: Metadata scripting

* **User Story**: As an editor, I want to convert a CSV of timestamps into timeline markers and YouTube chapters.

### Phase 4: Audio

* **User Story**: As an editor, I want one-click audio normalization for the entire track.

## Use Cases

1. **Daily Vlogging**: Rapidly importing standard intro/outro graphics and normalizing voiceover.
2. **Tutorial Creation**: Auto-generating markers for step-by-step sections.
